# Karten-Assets der Detailkarte

Schriften (Glyphen-PBF) und Sprites für den Protomaps-Basemap-Stil, gleich-originig ausgeliefert (CSP, offline).

- Quelle: https://github.com/protomaps/basemaps-assets (Branch `main`, abgerufen 2026-10-08 über raw.githubusercontent.com)
- `fonts/`: Noto Sans Regular/Medium/Italic, Glyphenbereiche 0–1279, 7680–7935, 8192–8447 (Latein inkl. Erweiterungen, Griechisch, Kyrillisch, Satzzeichen). Lizenz: SIL Open Font License 1.1 (`fonts/OFL.txt`). Fehlende Bereiche (z. B. CJK) werden nicht gebündelt; MapLibre zeichnet CJK über lokale Systemschriften.
- `sprites/v4/`: light/dark @1x/@2x. Lizenz: MIT, abgeleitet aus tangrams/icons (`sprites/LICENSE-tangrams-icons.md`).
